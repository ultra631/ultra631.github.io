08 — FAQ

Questions fréquentes

Combien ça coûte, un site web?+
Les prix débutent à 499 $ pour un site vitrine simple. Le forfait Pro à 999 $ couvre la majorité des projets PME, restaurant ou créateur. Pour les projets complexes avec base de données et fonctionnalités avancées, on discute d'une soumission personnalisée. Dans tous les cas, le prix est fixe et connu à l'avance.
Ça prend combien de temps?+
Un site Essentiel est livré en environ 1 semaine. Un site Pro prend environ 2 semaines. Les projets sur mesure varient selon la complexité, mais je vous donne toujours un délai précis dans la soumission — et je le respecte.
Puis-je modifier mon site moi-même?+
Absolument. Le code source vous appartient entièrement. Je vous explique les bases pour modifier le texte et les images. Pour les modifications plus complexes, je suis disponible à tarif horaire, ou via un forfait de maintenance mensuel.
Vous faites l'hébergement?+
Oui! Les sites simples sont hébergés gratuitement sur GitHub Pages. Pour les projets plus complexes, je recommande et configure un hébergeur adapté. Le nom de domaine est votre responsabilité, mais je vous guide étape par étape pour l'acheter et le connecter.
Vous travaillez avec des petits budgets?+
Oui. Le forfait Essentiel à 499 $ est conçu pour les budgets limités. Je propose aussi un paiement en deux versements (50% au début, 50% à la livraison). Si votre budget est encore plus serré, discutez-en avec moi — on trouve souvent une solution.
