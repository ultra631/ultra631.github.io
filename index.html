Questions fréquentes

FAQ

Combien ça coûte, un site web? +
Les prix débutent à 499 $ pour un site vitrine simple (1 à 3 pages). Le forfait Pro à 999 $ couvre la majorité des projets PME, restaurant ou créateur. Pour les projets complexes avec base de données, portail membre ou fonctionnalités avancées, on discute d'une soumission personnalisée. Dans tous les cas, le prix est fixe et connu à l'avance — pas de mauvaises surprises.
Ça prend combien de temps pour avoir mon site? +
Un site Essentiel est livré en environ 1 semaine. Un site Pro prend environ 2 semaines. Les projets sur mesure varient selon la complexité, mais je vous donne toujours un délai précis dans la soumission — et je le respecte. Tout commence dès que le premier versement est confirmé.
Puis-je modifier mon site moi-même après la livraison? +
Absolument. Le code source vous appartient entièrement. Je vous explique les bases pour modifier le texte, les images et les couleurs. Pour les modifications plus complexes, je suis disponible à un tarif horaire avantageux. Le mois de support inclus dans le forfait Pro couvre les petits ajustements post-livraison.
Vous faites l'hébergement du site? +
Oui! Les sites simples sont hébergés gratuitement sur GitHub Pages (idéal pour les sites vitrine). Pour les projets plus complexes, je recommande et configure un hébergeur adapté à votre budget. Le nom de domaine est votre responsabilité, mais je vous guide étape par étape pour l'acheter et le connecter — c'est très simple.
Vous travaillez avec des petits budgets? +
Oui, c'est important pour moi. Le forfait Essentiel à 499 $ est conçu pour les projets avec un budget limité. Je propose aussi un paiement en deux versements (50 % au début, 50 % à la livraison). Si votre budget est encore plus serré, discutez-en avec moi — on trouve souvent une solution adaptée à la réalité des petites entreprises et des créateurs qui débutent.
